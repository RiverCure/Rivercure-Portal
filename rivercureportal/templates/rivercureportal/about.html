{% blocktrans %}A Context, or geographic Context, refers to a specific geographic area, pertinent to modeling and analyzing flood events. A Context can be linked to a hydrological feature, such as a river, river basin, estuary, or lake. Each context is defined by a name, sensors, and various geographic characteristics.{% endblocktrans %}

{% blocktrans %}A Contribution is a set of information contributed by the user, regarding a real-life situation they have observed.{% endblocktrans %}

{% blocktrans %}An Event is a real or simulated set of occurrences taken place during a given period in a given geographic area.{% endblocktrans %}
